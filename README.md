# LifeLink – Blood Donation Camp Management System

## Project Overview
LifeLink is a responsive and interactive frontend website designed to make the initial process of participating in blood donation camps simpler, more organised and convenient.

It provides users with information about blood donation camps, preliminary eligibility checking, donor registration and appointment booking.

## Problem Statement
Finding suitable blood donation camps, understanding basic eligibility requirements and completing the registration process can sometimes be challenging. LifeLink aims to bring these facilities together in one user-friendly platform.

## Objectives
- Simplify the initial donor registration process.
- Provide preliminary donor eligibility information.
- Display available camp locations.
- Allow users to select appointment dates and time slots.
- Provide useful blood group compatibility information.

## Features
1. **Homepage:** Introduction to LifeLink and easy navigation.
2. **Donor Registration:** Registration form with input validation.
3. **Eligibility Checker:** Preliminary eligibility checking based on basic conditions.
4. **Camp Locations:** Information about available donation venues.
5. **Appointment Booking:** Frontend appointment selection and confirmation.
6. **Collection Progress Dashboard:** Displays collected units against the camp target.
7. **Blood Group Guide:** General red blood cell donation compatibility information.
8. **FAQs:** Answers to common questions about blood donation.

## Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling, layout and responsive design.
- JavaScript – Functionality, validation and interactivity.

## Project Structure
- `index.html` – Main HTML file.
- `style.css` – Website styling.
- `script.js` – JavaScript functionality.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
4. Explore the different sections of LifeLink.

## Important Note
LifeLink is a frontend project developed for educational purposes. Registration and appointment confirmations are frontend demonstrations and do not involve permanent data storage or actual reservations. The eligibility checker provides preliminary information only; final donor eligibility must be determined by qualified medical professionals.
